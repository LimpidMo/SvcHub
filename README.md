# SvcHub

一个 KernelSU / Magisk 服务管理模块，开机自动启动和保活 Termux 服务与二进制服务，并提供 WebUI 聚合管理服务


## 功能概览

### 两类服务

| | Termux 服务 | 二进制服务 |
|---|---|---|
| 运行环境 | Termux（以 Termux 用户身份执行） | 系统 root 环境 |
| 工作目录 | `/data/data/com.termux/files/home` | 可配置，默认 `/data/media/0/Server` |
| 附加参数 | 如 `-g 3003` 网络权限，`-u 10123` 指定用户运行 | 无,默认 |

每个服务可配置：
- **服务名称**：唯一标识，用于日志和进程 pid 文件管理
- **端口**：仅标识用，用于状态页"打开"按钮跳转浏览器
- **启动命令**：实际执行的 shell 命令（支持 `&` 并行服务、多行命令使用`;` 按顺序拼接）
- **自动启动**：开启则开机自动拉起 + 保活；关闭则仅手动启动

### 巡检保活

每隔固定间隔（默认 60 秒，可配置 5~86400 秒）执行一次巡检：
- 开机后自动启动时带有 start 绿色标签的服务，即开启“自动启动 & 保活”的服务
- 每次巡检检查start 状态的服务，如未启动或已被系统杀死则启动服务
- 更改检查间隔时间后，建议重启手机能尽快生效。


## WebUI 使用

在KernelSU 或 Magisk 管理器 → 模块 →  点击打开 SvcHub → 进入 WebUI。页面可左右滑动查看，自动刷新页面数据。

### 服务状态页

显示所有服务的运行状态：
- **绿色圆点** = 运行中，**灰色** = 已停止
- 服务管理：**启动** / **停止** / **重启** / **日志**
- 点击服务项可展开查看启动命令
- 带端口的服务运行时显示 **打开** 按钮，点击直接跳转浏览器，打开对应服务页 `http://127.0.0.1:port`

### 配置管理页

**基本设置**
- **检查间隔**：巡检周期，右侧 **日志** 按钮查看 supervisor 日志
- **调试** 按钮：显示所有调用的执行记录，排查问题时使用

**开机命令 & 测试命令**
- 默认编辑开机命令，点击框外自动保存
  - 可启动如adbd方便局域网调试、启动软件无障碍服务命令等等   
- 开启 **测试** 开关后进入测试模式：
  - 编辑内容不会影响开机命令
  - 右侧出现运行按钮：**以 termux 运行**（切换 Termux 用户 + 环境）/ **运行**（root 环境）
  - **日志** 按钮：开关关 → 查看开机命令日志，开关开 → 查看测试运行日志

**服务列表**
- 点击 **添加** 配置新服务
- 点击 **编辑** / **删除** 管理已有服务
- 点击 **排序** 进入拖拽排序模式，调整服务界面顺序及启动顺序

## 配置文件

存储于模块目录下 `config.json`，升级安装时自动保留。

## 服务目录
Termux 服务默认工作目录 `/data/data/com.termux/files/home`：
- 可自在该目录下在创建一个 `Server` 文件夹，统一放置和管理服务数据（非必须，只是防止在数据项多时数据管理）。如 openlist 放在`/data/data/com.termux/files/home/Server/openlist`，则启动命令填 `cd ./Server/openlist;openlist server --data ./data`,若是首次启动 openlist 记得去日志中查看登录密码 passowrd
- 或启动命令直接填写`openlist server`，跟在 termux 中启动 openlist 相同,端口填写 5244 ,启动后即可打开所对应服务页。
- 更新服务：在 Termux 使用 `pkg update & pkg upgrade -y` 更新全部或 `pkg update & pkg install -y 服务名1,服务名2` 更新单个或多个。

二进制服务默认工作目录 `/data/media/0/Server`，请确保：
- `/storage/emulated/0`创建的文件夹自动转换为可执行服 `/data/media/0/`
- 二进制文件已设置可执行权限（`chmod +x`）
- 依赖的库文件与二进制放在同一目录
- 若服务及配置 Server/xxx 文件夹下，先执行 `cd ./xxx;` 设置为工作目录,方便读取文件夹及数据

## 安装

1. 下载模块 ZIP
2. 在 Root 中管理器 → 模块 → 从本地安装，选择对应 ZIP 文件
3. 安装完成后重启设备

升级时会自动保留已有配置。

## 注意事项 （重点）

- 【请自行确认服务以及命令的的安全性，再到放到模块中应用和执行。自行对操作和处理负责】
- Termux 服务依赖已安装的 Termux 应用，下载对应的包，如 openlist 使用 `pkg update & pkg install -y openlit`
- 所有脚本为 POSIX sh，兼容 Android `/system/bin/sh`
- 玩机有风险，请自行备份数据，防止数据丢失。代码全公开请自行检阅后按需刷入。
