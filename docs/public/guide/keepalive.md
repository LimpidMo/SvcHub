# 巡检保活

每隔固定间隔（默认 60 秒，可配置 10~86400 秒；高于 60 则分片休眠，以保证配置热更新和功能检查）执行一次巡检。

## 做什么

- 开机后自动启动带有 start 绿色标签的服务，即开启「自动启动 & 保活」的服务
- 每次巡检检查 start 标签的服务，如未启动或已被系统杀死则重新启动服务
- 更改检查间隔后一分钟内生效，并打断原有间隔，即时按新间隔巡检
- 服务日志超过 1MB 轮转保留最近 1/4，保持近期日志上下文的同时避免日志无限增长
- 若启停功能开启，巡检同时执行启停功能检查

## 不做什么

- 不会杀死已启动的 stop 标签服务，避免临时手动启动的服务被误杀
- 不做 WakeLock 唤醒锁，因设备而异可能因锁屏 Doze 策略推迟至亮屏才响应功能恢复巡检，但这一般不影响日常使用体验
